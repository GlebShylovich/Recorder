# Instrukcja dla AI / Context Hand-off: EMANAGER Pomoc

Уважаемый ИИ-ассистент! Этот проект — декомпилированное WPF-приложение на .NET 10, в которое интегрирована система автообновлений через GitHub Releases, прелоадер (экран загрузки) и нативные уведомления.

Перед тем как вносить любые изменения в код, пожалуйста, ознакомься с текущей архитектурой, правилами безопасности и реализованными задачами ниже.

---

## 1. Архитектура основы (Текущее состояние)

1. **Экран загрузки (views/preloaderwindow.xaml)**:
   * Открывается первым при запуске. Имеет темный дизайн и спиннер (одна плавная полоска).
   * Запускает опрос GitHub API. Если обновлений нет — переключается на рабочее окно. Если есть — показывает кнопки «Aktualizuj» и «Pomiń» прямо внутри себя.
2. **Служба автообновления (ScreenRecorderApp.Services/UpdaterService.cs)**:
   * Проверяет новые версии на GitHub (`v1.x.x`). Скачивает установщик `SetupEManagerPomoc.exe`.
   * Создает временный `.bat` скрипт, который закрывает программу, запускает тихий инсталлятор и затем запускает обновленную программу из папки установки.
3. **Окно изменений (views/changelogwindow.xaml)**:
   * Содержит парсер Markdown, который красиво рендерит описание релиза с GitHub.
4. **Служба уведомлений (ScreenRecorderApp.Services/NotificationService.cs)**:
   * Выводит нативные Toast-уведомления Windows. Автоматически регистрирует `AppUserModelId` в реестре текущего пользователя (`HKCU`).
5. **Сборщик Inno Setup (setup.iss)**:
   * Настроен с параметром `PrivilegesRequired=lowest` для тихой установки в папку пользователя `%APPDATA%\EMANAGER Pomoc` без запроса прав администратора (UAC).
   * Автоматически регистрирует в Планировщике задач Windows ежедневный запуск уведомления-напоминания на 14:00.

---

## 2. Чек-лист для нового ассистента: Что проверить перед изменением кода?

1. **Проверь наличие файлов:**
   * Убедись в существовании `PreloaderWindow.cs`, `UpdaterService.cs`, `NotificationService.cs`, `ChangelogWindow.cs` и соответствующих `.xaml` файлов.
2. **Изучи частичные (partial) классы:**
   * Классы окон объявлены как `partial`. Все дубликаты свойств/методов, генерируемые WPF (такие как `InitializeComponent()`, `_contentLoaded` и поля элементов), вынесены в автогенерируемый код и отсутствуют в основных `.cs` файлах во избежание конфликтов компиляции.
3. **Проверь обработку ShutdownMode:**
   * В `App.cs` на время старта выставлен `ShutdownMode.OnExplicitShutdown`, чтобы закрытие окна списка изменений не завершало работу всего приложения. При переходе к главным окнам он возвращается в `ShutdownMode.OnLastWindowClose`. Не ломай эту логику!

---

## 3. Правила компиляции и сборки релиза

Для успешной работы автообновлений и запуска без требования скачивания .NET на клиентских ПК, приложение должно компилироваться как **Self-Contained** (самодостаточное):

* **Команда сборки:**
  ```powershell
  dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=false -p:PublishReadyToRun=false
  ```
  *Папка публикации:* `bin\Release\net10.0-windows10.0.19041.0\win-x64\publish\`
* **Сборка инсталлятора:**
  Инсталлятор собирается через Inno Setup с помощью скрипта `setup.iss`, который упаковывает файлы именно из папки публикации `publish\*` выше.

## 4. Реализованное напоминание (Task Scheduler)

В версии `1.5` мы внедрили ежедневные уведомления-напоминания без утяжеления оперативной памяти пользователя (без фонового висения в трее):

1. **Аргумент `--silent-notification`:**
   В `App.cs` при запуске проверяется аргумент командной строки. Если он передан, приложение запускается скрыто, вызывает нативное уведомление и моментально завершает свою работу с помощью `Shutdown()`.
   * **Заголовок:** `Zauważyłeś błąd w systemie?`
   * **Текст:** `Nie trać czasu na pisanie. Nagraj ekran i zgłoś problem w 30 sekund!`
2. **Авторегистрация в Windows Task Scheduler через Inno Setup:**
   * При установке (секция `[Run]`) автоматически создается системная задача с именем `"EMANAGER Pomoc Reminder"`, запускающаяся каждый день в 14:00.
   * При удалении (секция `[UninstallRun]`) эта системная задача корректно стирается.
